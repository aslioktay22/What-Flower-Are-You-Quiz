# Flower Personality Quiz

A short personality quiz that asks a series of questions and reveals which flower best matches your personality. One of my first web projects, built while learning HTML, CSS, and JavaScript.

## How to run

1. Clone or download this repository
2. Open index.html in your browser
3. Answer the questions and see your result!

## Project structure

flower-quiz/
- Photos/
- Quiz_Page/
- Results/
- index.html
- styles.css

## What I learned

- HTML page structure and linking pages together
- CSS styling and layout
- JavaScript conditionals and logic
- Organising a multi-page project
